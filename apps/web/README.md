# CodeRoom Web

Для Angular 22 нужен Node.js `^22.22.3`, `^24.15.0` или `>=26.0.0`.

Минимальный Angular-клиент для проверки совместного документа через SignalR.

## Запуск

1. Запустите API с профилем `http` (`http://localhost:5085`).
2. В `apps/web` выполните `npm ci` и `npm start`.
3. Откройте `http://localhost:4200/projects/1`, подставив ID существующего проекта. Выберите файл в дереве, чтобы открыть его в Monaco.

Angular dev server проксирует `/api` и `/hubs` на API через `proxy.conf.json`, включая WebSocket для SignalR. Если API слушает другой адрес, измените `target` в этом файле.

Клиент подписывается на `DocumentUpdateReceived` до запуска соединения, затем вызывает `JoinFile(projectId, fileId)` и `GetCollaborativeDocumentUpdatesAsync(projectId, fileId)`. Для пустого файла результат `[]`, счётчик исходных обновлений равен 0. Обновления из истории и событий декодируются из Base64 и применяются к `Y.Doc`; текст хранится в `Y.Text` с ключом `content`. `text.observe` обновляет поле редактирования, а `document.on('update')` отправляет только локальные изменения через `UpdateCollaborativeDocumentAsync`. Новые события считаются отдельно.

Локальные обновления остаются в `pendingUpdates` до успешного ответа Hub. `disconnect` не удаляет их; при повторном подключении к тому же файлу клиент восстанавливает их в документе и повторяет отправку с исходными `updateId`. Для каждого обновления допускается не более трёх отправок; после третьей ошибки его статус становится `needsAttention`, и автоматические повторы прекращаются. Очередь хранится только в памяти вкладки и пропадёт после перезагрузки страницы.
